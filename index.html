Detox Life — User Manual

A practical guide to setting up your workspace, planning your days, learning full-stack development, and protecting your data.

Welcome to Detox Life

Detox Life is a personal productivity and learning workspace. Use it to plan daily tasks, track routines, work through the 10-phase Full-Stack Roadmap, and review your consistency. Your information is stored in this browser on this device; the app does not automatically sync it to an online account.

Recommended first steps: (1) review Settings, (2) add today's tasks, (3) enter classes or other busy commitments, (4) open the roadmap and mark your current learning progress, and (5) export a backup after making important changes.

1. Navigation

  • Desktop: use the navigation buttons near the top of the page.
  • Phone: open the Navigate dropdown and choose the section you want.
  • Overview: your daily snapshot and progress.
  • Daily Planner: create and manage dated tasks and busy blocks.
  • Full-stack Roadmap: track topics and projects across 10 phases and customize the roadmap.
  • Streak & Calendar: inspect monthly consistency and select a date to review its tasks.
  • Settings: adjust planning targets, track sleep/water/meals, export or import data.
  • User Manual: return to this guide whenever needed.

2. Dashboard / Overview

The Overview summarizes the selected day. It shows daily completion, completed tasks, planned workload, current streak, today's task list, daily essentials, a 7-day consistency chart, and available-time estimates.

  • Use Previous and Next to inspect another date; choose Today to return to the current date.
  • Use Manage today's plan to jump to the planner.
  • Completion percentage is based on the selected day's planned tasks. If no tasks exist for that day, the app displays 0% rather than assuming the day is complete.
  • The capacity panel estimates available time after busy blocks and break buffer. If unfinished tasks exceed usable time, treat the red warning as a prompt to reprioritize.

3. Daily Planner — step by step

  1. Open Daily Planner and select the date.
  2. Enter a task name, category, priority, date, estimated minutes, and optional notes.
  3. Choose Add task. The task appears in the scheduled-task list.
  4. Use Edit to change a task. Use the delete (×) control to remove it after confirming.
  5. Tick the checkbox when the task is complete. Changes are saved automatically.
  6. Use the search box and filters to find tasks by name or status, including overdue tasks.
  7. Enter the day's available hours and break/buffer hours. These values are saved for that date.
  8. Add busy blocks for classes, appointments, or other commitments by entering a name and start/end time. Remove a block if it changes.

Planning logic: the capacity estimate subtracts busy-block duration and your break buffer from available hours. It compares that usable time with scheduled work. It is a planning estimate, not a calendar alarm or automatic external calendar integration. You still decide which tasks to do and when.

Deadline behavior: tasks are associated with a date. An incomplete task dated before today is marked overdue. Set the correct date when creating or editing tasks.

4. Full-Stack Roadmap — learn and customize

The roadmap contains 10 phases, from JavaScript Fundamentals through Advanced Engineering & System Design. Each phase contains topic sections and a project. Use it as a checklist of concepts you can explain and apply—not just videos you have watched.

Mark learning progress

  1. Open Full-stack roadmap.
  2. Expand a phase by selecting its header.
  3. Tick a topic when you understand it well enough to explain it and use it in code.
  4. Tick the phase project when you have completed the project to your own acceptable standard.
  5. Use search to find a topic and the filter to show all, incomplete, or completed items.

Customize any phase

  • Use + Add topic/task to add a topic, a new section, or a project to a chosen phase.
  • Use a section's add/edit controls to create or rename sections and add/edit topics.
  • Use the phase customization control to edit a phase title and its short description.
  • Edit the phase project name when your project scope changes.
  • Custom topics and sections are saved along with their completion state. Adding items changes the total used for progress calculations.
Tip: add missing subjects to the relevant phase instead of deleting the original roadmap. Export a backup before major restructuring. A topic checkbox records your progress; it does not automatically validate your knowledge.

5. Streak & Calendar

  • Use the arrows to move between months.
  • Select a day in the calendar to open that date in Daily Planner.
  • A day qualifies for the streak when it has planned tasks and reaches the configured completion threshold (80% by default).
  • The app displays current and best streak information based on saved daily task records.
  • Days with no planned tasks are not automatically treated as missed days.

Streaks are intended to encourage consistency, not guilt. If a day becomes unrealistic, adjust the plan and continue the next day.

6. Settings & Daily Essentials

  • Usual available hours: default daily time capacity used when a date has no custom value.
  • Default buffer hours: time reserved for breaks and unexpected interruptions.
  • Streak threshold: the completion percentage required for a day to qualify.
  • Sleep and water targets: editable tracking targets.
  • Default daily coding minutes: a planning preference for coding practice.
  • Select Save settings after changing the settings form.
  • In Daily Essentials, record actual sleep hours and water consumed for the selected day, then save. Check the meal boxes as you complete them.

Sleep, water, and meal tracking are separate from task completion. The default values are personal planning targets, not medical advice.

7. Saving, Export & Import

Automatic saving

Most edits are saved to browser localStorage when you add, edit, delete, or check an item. Reloading the page should retain saved data in the same browser profile, as long as browser storage remains available.

Export a backup

  1. Choose Export backup at the top or in Settings.
  2. Your browser downloads a JSON backup file. Keep it somewhere safe, such as a personal folder or cloud drive.
  3. Export again after significant roadmap edits or at regular intervals.

Import a backup

  1. Choose Import backup and select a Detox Life JSON backup.
  2. Read the confirmation prompt carefully. Import replaces the current saved app data.
  3. After import, check the roadmap, tasks, and settings to confirm the expected information is present.
Important: localStorage is tied to the browser profile and device. It is not cloud sync. Private/incognito sessions, clearing browser/site data, changing browsers, or using another device can make the saved data unavailable. Export backups before clearing data or moving devices. The Clear all app data button is destructive and cannot be undone without a backup.

8. Recommended daily workflow

  1. Morning: check the date, add your priorities, and enter classes or other commitments.
  2. Plan realistically: set available hours and break buffer, then check for overload.
  3. Study: choose a small number of roadmap topics and practice them in code.
  4. Build: connect learning topics to the current phase project where possible.
  5. During the day: mark tasks complete and adjust estimates when plans change.
  6. Evening: update sleep/water/meal tracking, review completion, and prepare tomorrow's tasks.
  7. Weekly: review the calendar and export a backup.

Prefer sustainable progress over filling every available hour. Leave room for breaks, unexpected tasks, and sleep.

9. Troubleshooting

My data disappeared

Check that you opened the same HTML file in the same browser profile. If browser storage was cleared, restore from a previously exported JSON backup. The app cannot recover data that was deleted without a backup.

Changes do not survive a reload

Make sure browser storage is enabled and the page is not running in a restricted private session. Try exporting a backup, then reopen the HTML file in a normal browser window. If storage is full or blocked, the app may show a save warning.

Import did not work

Use a JSON backup exported from Detox Life. Confirm that you selected the correct file. Import replaces current data only after you approve the confirmation prompt.

My time estimate looks wrong

Check the selected date, available hours, buffer hours, and busy-block start/end times. Make sure task durations are entered in minutes and that tasks are assigned to the intended date.

I cannot find a roadmap item

Clear the roadmap search box and select the “All topics” filter. The item may be in another phase or section.
